What Tali adds

Scruff keeps Ruff’s speed and Black-compatible baseline, then opts into Tali mode for layout choices that preserve intent: column alignment you wrote on purpose, quotes that distinguish symbols from prose, and wrapping that spends vertical space wisely.

Rule showcase

Each formatting rule, side by side

Standard Ruff layout on the left. Tali mode on the right.

01

Symbol quote style

Identifier-like strings get single quotes; natural-language text keeps double quotes. Nesting inside f-strings follows the same classification.

format.quote-style = "symbol"

02

Side-effect imports

Alias a module as _ to mark an intentional side-effect import. Member imports aliased to _ still count as unused.

03

Grouped signatures

/ and * are semantic block delimiters. Parameters pack within each block; long names still wrap by width.

04

Rectangular data

Extra whitespace that lines up columns is treated as alignment intent. Cells format normally, then column widths (and decimal points) are enforced across the matrix — including nested tensors and row comments.

05

Nested container hug

When a call’s only argument is a multiline list, tuple, set, or dict, Tali hugs the delimiters instead of adding another indentation layer.

06

Compact parentheses

Prefer an expression’s own split points before wrapping it in stand-alone parenthesis lines. When parens are needed, keep them beside the expression or use a compact hanging layout.

07

Horizontal alignment

Extra source spacing opts consecutive related statements into alignment: = operators, annotation content after :, and trailing comments when a wide gap signals intent.

08

Pointer comments

Trailing comments never force the code before them to wrap. If the full line exceeds the width, the comment drops below as a pointer (# ^ …). Pragmas stay attached.

Enable Tali mode

Pin Scruff’s version before turning Tali on in automated format workflows.

# pyproject.toml
[tool.scruff]
mode = "tali"

[tool.scruff.format]
quote-style = "symbol"
quote-symbol-regex = "^[A-Za-z_][A-Za-z0-9_.-]*$"
# or scruff.toml
mode = "tali"

# CLI
scruff format \
  --config "format.quote-style = 'symbol'" .
